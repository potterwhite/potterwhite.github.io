SalvageOfSDK

厂商以 .tar.gz 分发的大型嵌入式 SDK,没有版本历史、没有 repo 链路。把它恢复成由几十到上百个子仓库组成、可 repo sync 一键拉取、且编出的镜像能正常启动的 SDK —— 这件事我在两代 SOC 上各做了一轮。

  • 第一次迭代（2025） — RV1126B / RK3568。原版 SDK,repo 清单完好。Python 脚本解析清单 + GitLab API 批量建仓,重点是把流程改造落到团队。
  • 第二次迭代（2026） — RK3576。厂商深度定制,repo 链路已被销毁。Bash 工具链靠 find -name .git 自动推导出 58 个仓库,重点是无清单前提下的取证式重建。
