第一类：嵌入式 基础设施构建（Build Infrastructure）

让嵌入式工程师少踩坑的开发环境与脚手架——Developer Productivity 工具链。

本类别收录我做过的嵌入式研发效能工具：让工程师在嵌入式 Linux 项目中”换一台机器也能编过、新人第一天就能跑通”。其中 Bring-Up-Anything 把服务对象从人延伸到了 AI agent。

项目

  • Bring-Up-Anything — 把串口/SSH/交叉编译/烧写封装成 MCP 工具链，让 AI agent 自主完成开发板调试。
  • HarborPilot — 配置驱动的嵌入式 Linux 开发环境框架。
  • SalvageOfSDK — 把厂商以压缩包分发的大型嵌入式 SDK 恢复成 Git 多仓库协同体系，跨两代 SOC、两轮迭代。
  • SPIFlasher — 纯用户态逆向出的 FPGA 配置 Flash 烧写工装：55 KB 单文件，仅依赖 libc，浏览器驱动，全程回读校验。
